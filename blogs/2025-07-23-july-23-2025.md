v1 Deprecated Deprecation of Transport Layer Security (TLS) v1.0 and v1.1 protocols API Gateway now enforces TLS v1.2+. You can opt out of enforcing TLS v1.2+ for your API Gateway's new security settings by reaching out to Google Cloud Support to continue using your current protocol.
